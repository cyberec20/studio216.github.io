# Article source

This folder contains the canonical editable source for the future Studios216 bilingual article library.

- `es/` — Spanish Markdown bodies.
- `en/` — English Markdown bodies.
- `meta/` — one JSON metadata file per article family.

The generated HTML under `/articles/` is an output. Do not hand-edit generated article pages.

Before a version can be marked `published`, its metadata must include a passed Desire-Driven Copy validation report, passed SEO review and Franklin's human approval. See `/editorial/ARTICLE_WORKFLOW.md`.

No article content has been migrated in this foundation phase.
