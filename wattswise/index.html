Built around a recurring engineering problem: repeated setup.

WattsWise grew out of a simple workflow problem: when a project changes, the same values and assumptions often have to be re-entered across separate calculations.

The goal is not to replace spreadsheets or engineering review. It is to make related electrical calculations easier to revisit, reuse, and adjust while keeping the inputs visible.

That means connected context where it helps and manual control when the engineering case needs a different assumption.

Frequently asked questions

What makes WattsWise different from a set of separate calculators?

According to the current product description, its connected core is designed so relevant values can move between related calculations without preventing manual overrides. The goal is to reduce repeated setup while keeping the inputs and assumptions visible.

What calculations does WattsWise include?

The current product listing describes several groups of tools. These include power-triangle analysis and voltage drop; point-to-point short-circuit/fault-current estimates; conductor and conduit utilities; and advanced tools such as power-factor correction, current imbalance, insulation resistance/DAR/PI, and project-file functions.

Can I change values manually?

Yes. According to the current product description, connected values are intended to reduce repeated entry, not force every module to use the same assumption.

Does WattsWise determine NEC, IEC, or local-code compliance?

No. WattsWise supports calculations. You remain responsible for applicable standards, project requirements, equipment data, and safety conditions for the real installation.

Is WattsWise only for engineers?

No. It is intended for electrical engineers, electricians, contractors, and technical students who want practical calculation tools while retaining visibility into the values used.

Does it work offline?

The current product listing describes core electrical calculation tools as usable offline. Any feature that depends on an external service should be represented according to its actual behavior in the released app.

Where can I install it?

WattsWise is available for Android on Google Play.
